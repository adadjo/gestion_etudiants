# gestion_etudiants

Petite application Python de **gestion des étudiants**, réalisée dans
le cadre du cours *Industrialisation du développement* (Séquence 2 :
Git et GitHub).

## Objectif

Servir de projet-support pour s'entraîner au versionnement avec Git et
à la collaboration avec GitHub : commits, dépôt distant, branches de
fonctionnalité et fusion.

## Fonctionnalités

- Afficher le nom d'un étudiant (branche `feature/ajout-etudiant`)
- Rechercher un étudiant (à venir)
